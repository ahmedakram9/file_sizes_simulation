Ask the class: at what resolution could you first tell what it was? What happened to the file size each time we doubled the width and height?
AnswerEach step doubles the width and the height, so there are 4× as many pixels, and the file is 4× bigger. More pixels means more detail but a bigger file.

Challenge: load the smiley or the cat, then click 8×8 → 16×16 → 32×32 → 64×64. What details appear that weren't there before?
AnswerAt 8×8 you only get a rough shape. With more pixels the curves get smoother, and small details appear: the eyebrows, the shine in the eyes, rosy cheeks, the cat's whiskers. More pixels = higher resolution = more detail. But 64×64 needs 64 times more pixels than 8×8, so the file is much bigger.

Ask the class: Why would the café want its logo as an SVG? When would a bitmap be the better choice?
AnswerAn SVG logo can go on a business card or a 3-metre sign and stay perfectly sharp, and the file stays small. But photos can't be made from simple shapes, so photos are always bitmaps.
